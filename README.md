# 🛒 Simple Shopping Cart

A simple **Shopping Cart application** built with Python. This project demonstrates basic shopping cart operations such as adding products, viewing items, calculating the total price, and managing a cart.

## ✨ Features

- 🛍️ Add products to the cart
- 🧾 View cart items
- 💰 Calculate total price
- ❌ Remove items from the cart
- 🛒 Simple shopping cart interface
- 🐍 Built with Python

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/laibashahadat/Simple-Shopping-Cart.git
```

3. Open the project folder.
4. Run the Python file:

```bash
python "Project 2 . 🛒 Simple Shopping Cart.py"
```

## 🎯 Purpose

This project was created to practice Python programming concepts such as variables, lists, loops, conditional statements, functions, and user input.
